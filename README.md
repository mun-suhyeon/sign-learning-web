# 손끝 한국수어

한국수어 지문자와 기초 단어를 배우고, 웹캠 손 인식(MediaPipe)으로 직접 연습하는 웹사이트입니다. 영상은 브라우저 안에서만 처리됩니다.

## 실행

```bash
npm install      # postinstall에서 MediaPipe wasm·모델을 public/mediapipe 로 준비
npm run dev
```

모델 다운로드가 실패했다면 `npm run setup` 으로 다시 받을 수 있습니다.

## 기능

- **배우기**: 지문자 24자 / 기초 단어 22개. 각 항목에서 국립국어원 한국수어사전 공식 영상으로 연결
- **지문자 연습**: 순서대로 · 복습(라이트너 방식) · 60초 도전 · 단어 철자. 정답 손 모양을 0.7초 유지하면 통과
- **단어 거울 연습**: 거울 화면 + 4초 녹화 후 반복 재생
- **기준 동작 등록**: 글자별 손 모양을 녹화하면 그 샘플(k-NN)로 채점. JSON으로 내보내기/가져오기

## 채점 기준에 대한 주의

`src/data/jamo.ts`의 `rule`은 카메라 채점용 **임시 근사 규칙이며 한국수어 전문가 검수 전**입니다(11자만 규칙 있음).
정확한 기준은 숙련자가 '기준 동작 등록'으로 녹화한 샘플을 내보내 공유하는 방식을 권장합니다.

## 스모크 테스트

```bash
npm run dev                               # 다른 터미널에서
npm run smoke http://localhost:5173       # 설치된 Chrome으로 전체 흐름 확인, 스크린샷은 .smoke/
```

손 사진(`.smoke/hand.jpg`, 또는 `HAND_IMAGE` 환경 변수)을 가짜 카메라로 넣어 손 인식까지 확인합니다.
